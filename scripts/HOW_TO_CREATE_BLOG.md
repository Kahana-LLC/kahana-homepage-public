# 📝 How to Create a Blog Post

## ✨ Easiest Way: Just Tell Me in Chat!

Just say:
```
Create blog: Comet vs Chrome vs Oasis, date: 2026-01-22, author: Konika Dhull, image: https://example.com/image.jpg, links: https://source1.com, https://source2.com, https://source3.com
```

I'll create everything automatically! 🎉

---

## 📄 Or Use Text File (Backup Option)

Create a file `my-blog.txt`:

```
TOPIC: Comet vs Chrome vs Oasis
DATE: 2026-01-22
AUTHOR: Konika Dhull
IMAGE: https://example.com/image.jpg
LINKS:
https://source1.com
https://source2.com
https://source3.com
```

Then run:
```bash
node scripts/create-blog-simple.js my-blog.txt
```

---

## What You Need

- ✅ **Topic** (e.g., "Comet vs Chrome vs Oasis")
- ✅ **Date** (e.g., "2026-01-22" or "Jan 22, 2026")
- ✅ **Author** (e.g., "Konika Dhull")
- ✅ **Image URL** (paste the picture link)
- ✅ **Source Links** (all your research URLs)

That's it! Everything else is automatic.

---

## After Creation

1. I'll create the blog post JSON file
2. Update the blog index automatically
3. Generate a prompt file for content generation
4. You just need to generate the HTML content using the prompt

**Time: ~20 minutes total!** 🚀
